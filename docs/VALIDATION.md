# Проверки

Автотесты: рендер всех шаблонов, YAML, варианты заглушки, IPv6 bypass/rescue,
отказ опасных конфигураций, безопасные аргументы helper, атомарная замена
firewall, Compose isolation и порядок запуска. Ansible syntax-check выполнен.
В среде сборки нет Docker daemon, nginx и привилегий управления nftables:
живой запуск на Ubuntu 24.04/26.04 и ACME не выполнен. Это обязательная
приёмка на тестовой VM; результат не подменён статическими тестами.

Во время развёртывания дополнительно выполняются `docker compose version`,
`nginx -t` с выбранным образом и настоящая атомарная nft-транзакция. Ошибка
не должна приводить к частичному применению правил или запуску proxy.

## Матрица приёмки (для каждой версии Ubuntu)

Используйте два независимых внешних IP, не входящих в bypass; для проверки
SSH SPA один из них не должен входить в rescue. Выполняйте HTTP проверки
новыми curl-процессами, чтобы не переиспользовать conntrack.

| Проверка | Ожидание |
|---|---|
| Чистое развёртывание | UI только по туннелю, nginx -t успешен |
| Без SPA, HTTP | страница/444/302 согласно режиму |
| Без SPA, HTTPS | заглушка после TLS; bootstrap даёт certificate error |
| Без SPA, произвольный Host/SNI | backend недоступен |
| Валидный SPA | сайты и защищённые порты доступны |
| Поддельный/повторно отправленный SPA | lease не добавлен/не продлён |
| Другой внешний IP без SPA | всё ещё заглушка |
| TTL истёк | новое соединение получает заглушку |
| Прямые 8081/8444/9000/9080/9180, до и после SPA | недоступны |
| IPv6 без bypass | заглушка, UI закрыт |
| Rescue SSH, без SPA | новое SSH соединение работает |
| HTTP-01 staging снаружи | сертификат выпущен; обычный URI остаётся закрытым |
| DNS-01 и renewal | сертификат выпущен/продлён самим UI |
| LAN/Internet upstream | запросы доходят, Host/SNI/TLS verify правильны |
| Backend firewall | прямой доступ клиента к origin закрыт |
| Новый сайт из UI | автоматически подчиняется SPA |
| Ansible повторно | UI-сайты, сертификаты, настройки сохранились |
| Reboot | firewall раньше proxy, leases пустые, данные UI сохранены |
| Остановка fwknop | существующий lease истекает без демона |
| Невалидный nft config | прежняя таблица остаётся, proxy start блокируется |
| Backup/restore | UI открывается, сертификаты и сайты сохранились |

Снаружи: `curl -v http://DOMAIN/`, `curl -vk https://DOMAIN/` для диагностики
self-signed, затем без `-k` после назначения доверенного сертификата.
Для TTL: отправьте SPA, проверьте nft expires, дождитесь TTL и выполните новый
curl. Для прямых портов используйте `nc -vz -w 3 SERVER PORT`.
Проверьте `ss -lntup`: UI backend — 127.0.0.1:9000, UI proxy — 127.0.0.1:9080.
После смены версии образа повторите проверку, что его startup не восстановил
публичный стандартный сайт UI. Не удаляйте bootstrap nginx-ui.conf без замены.
